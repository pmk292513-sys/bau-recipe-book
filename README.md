# 📖 바우 레시피 북 (Bau Recipe Book) - 오프라인 설치형 모바일 & A4 인쇄 시스템

인터넷(Wi-Fi, 데이터)이 전혀 없는 주방이나 야외, 비행기 모드에서도 **평생 영구적으로 스마트폰에 설치해 사용할 수 있는 오프라인 설치형 웹앱(PWA)**입니다.

---

## 📱 인터넷 없는 오프라인 설치형의 강점

1. **인터넷 연결이 필요 없는 100% 독립형**
   - 모든 화면, 폰트, 기능 스크립트가 스마트폰 기기 내부 메모리에 자동 영구 캐시(`sw.js`)됩니다.
   - 인터넷 연결이 완전히 끊겨도(비행기 모드에서도) 앱이 1초 만에 켜집니다.

2. **스마트폰 홈 화면에 진짜 앱으로 설치 (`manifest.json`)**
   - 브라우저 주소창이나 메뉴 없이 전체화면 앱 형태로 시원하게 열립니다.
   - 홈 화면에 예쁜 '바우 레시피 북' 전용 앱 아이콘이 생성됩니다.

3. **데이터 영구 보관 (Local Storage)**
   - 작성한 레시피는 스마트폰 내부에 안전하게 영구 저장됩니다.
   - 언제 어디서든 수정, 삭제, 조회가 가능합니다.

4. **실물 A4 규격 1:1 완벽 인쇄**
   - 사진칸 규격: 가로 13cm × 세로 9.5cm, 도톰하고 세련된 1.8px 테두리
   - 토핑 전용 분리 칸 (조리 내용의 끝자락에 자동 배치)
   - 요리 계량 단위 드롭다운: 밥숟가락, 한 꼬집, 종이컵, g, Oz, ml 등
   - 또렷하고 굵은 글씨(`font-weight: 600~800`)와 진한 테두리선으로 A4 정중앙 출력

---

## 📲 스마트폰에 앱으로 설치하는 초간단 3단계

1. **컴퓨터에서 서버 실행**:
   - 터미널에서 `python app.py`를 실행합니다.
2. **스마트폰으로 접속**:
   - 같은 Wi-Fi 환경에서 화면에 뜬 **스마트폰 접속 주소**(예: `http://192.168.0.x:8080`)로 접속합니다.
3. **[홈 화면에 설치] 터치**:
   - 화면 상단에 뜨는 **[📲 홈 화면에 설치]** 버튼을 누르면 스마트폰에 앱으로 깔립니다.
   - *(아이폰의 경우: 사파리 하단 '공유' 버튼 -> '홈 화면에 추가' 선택)*

⭐ **설치가 완료되면 이제 컴퓨터를 끄고, 스마트폰의 인터넷을 완전히 꺼도 언제 어디서든 스마트폰 앱을 켜서 자유롭게 레시피를 작성하고 인쇄하실 수 있습니다!**
